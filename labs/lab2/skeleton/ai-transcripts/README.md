# AI transcripts

Commit the complete record of all your group's AI use here by the final
deadline (see the AI tool policy in the handout). It is not needed at the
midpoint checkpoint.

The record includes:

- the transcript of every web-based chat session (for example, an exported
  conversation);
- the complete session log of every command-line or IDE coding agent;
- the model name and version used in each case, and which group member used it.

Partial, summarized, or reconstructed records are not enough. The runs of the
lab's coding agent (`jobs/`) are not part of this record.

For a coding agent, commit the original session files, unchanged, in a folder
per tool (for example `claude-code/`, `codex/`, `opencode/`). `AGENTS.md` at the
root of the repository tells coding agents to do this whenever they commit.
If a log contains an API key or another secret, do not commit it as is: ask
the TAs what to do.
