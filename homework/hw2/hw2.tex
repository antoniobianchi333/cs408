\question Answer the following questions regarding subsumption:
\begin{parts}
\part[10] Does Node Coverage subsume Edge Coverage? Justify your answer.
\answerspace{10}
\answer{
    Yes. Proof No. Example: a path visiting nodes 1→2→3 covers all nodes, but may miss the edge (2,3) if traversal ends early. Node Coverage does not guarantee every edge is covered.y Contradiction or Induction accepted.
}
\part[10] Does Edge Coverage subsume Edge Pair Coverage? Justify your answer.
\answerspace{10}
\answer{
    No. Edge coverage requires the edge to be traveled once whereas each page coverage document is traversed more than once. 
}
\part[11] Does Edge Pair Coverage subsume Prime Path Coverage? Justify your answer.
\answerspace{10}
\answer{
    No. Prime path coverage requires all maximal simple paths. Due to this, there cannot the more than 2 edges. 
}
\end{parts}
